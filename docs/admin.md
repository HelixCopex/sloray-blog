# 管理后台

单人博客直接访问 `/login` 登录。访客导航不显示写作或登录入口；登录成功后进入
文章管理，并显示“管理后台”入口。再次访问 `/login` 会回到后台。
后台导航集中提供文章、页面、媒体、评论、账号和设置；作者只能访问自己的文章和评论。
顶部 Tab 位于正文动效之外，局部切页保留导航节点并更新当前选项；管理 Dock 使用服务器图标。
操作反馈以 Toast 弹出：蓝色信息、绿色成功、黄色提醒、红色错误，可手动关闭。

## 文章与 Markdown 写作

点击“新建文章”，填写标题、地址和正文。地址使用文字、数字、短横线或下划线，
公开地址为 `/posts/地址`。编辑器支持只编辑、只预览和分栏，输入后自动更新预览。
预览和公开正文使用相同的 Markdown 渲染与 HTML 清洗，支持列表、表格、代码和图片。

“保存后状态”决定 Dock 保存按钮的动作：保存草稿、保存修改或保存定时发布；发布按钮立即公开。
草稿只在后台可见；定时发布必须填写未来的北京时间，并需要运行 worker。
Ctrl/Cmd+S 保存；离开未保存的内容时浏览器会提示。发生版本冲突或地址重复时保留输入，
按提示更换地址或复制正文再重新加载。文章编辑后可查看修订历史。

点击“打开媒体选择器”，可以上传 PNG/JPEG/WebP 或取用媒体库中的图片。
图片处理完成后，点击图片会将 Markdown 图片链接复制到剪贴板，关闭选择器后粘贴到正文。
可以填写图片说明；剪贴板权限被拒绝时，下方显示可手动复制的链接。
封面通过媒体选择器的“设为封面”选择，也可以“移除封面”；保存文章后生效。
上传错误详情和重试见 [媒体文档](media.md)。

## 独立页面

管理员在“页面”中创建关于、联系、友链等内容，编辑和预览方式与文章相同。
页面地址位于根路径，例如 `about` 对应 `/about`；`login`、`admin`、`posts` 等系统路径不可使用。
保存草稿时不会公开；发布后立即生效，不需要构建前端。
勾选“显示在站点导航中”后，已发布页面会出现在导航里；排序数字越小越靠前。
不显示在导航的已发布页面仍可直接访问，并收录到 sitemap。撤回为草稿或删除后返回 404。
更改页面地址后旧地址返回 404，不会自动重定向。

新增 expand 迁移创建 `pages` 表，并将默认“关于”内容迁入数据库；不修改历史迁移。
更新现有部署时，按正常发布流程先执行 `sloray migrate up`。页面更新与 CDN purge 任务在
同一数据库语句内提交；运行 worker 消费 outbox。`404` 保留为应用错误页，使用公开主题并保持 404 状态。

单人使用无需创建额外账号；需要协作时才在“账号”创建作者或管理员。
所有后台页面提供退出登录；运行时设置仍由 Rust 渲染，保存逻辑保持原有验证和原子配置更新。

## 主题与外观

后台“主题”可导入/导出 JSON＋CSS 主题包，预览颜色、字体、宽度、导航及首页区块，保存后显式启用。
“背景与玻璃效果”可设置图片地址、背景模糊、遮罩和面板模糊；留空恢复纯色，详情见 [主题插件](themes.md#背景与模糊度)。
错误样式不会作用于后台；可随时恢复默认。详细说明与示例见 [主题手册](themes.md)。
全站使用 Material 3 图标与语义样式，公开页面外观按钮支持跟随系统、浅色与深色。

首页布局可在“主题 → 首页编排”调整区块顺序并配置便笺、标签、页面、RSS 组件域。
“设置 → 站点标识”独立保存站点名称和 Favicon；更多说明见 [主题手册](themes.md#首页编排与独立刷新)。

## 页面 Dock 与编辑操作

文章和自定义页面编辑器的保存、发布、媒体选择、已发布内容预览、删除入口位于 Dock；
手机先展开 Dock 即可查看编辑操作。状态选择保留草稿/立即发布/文章定时发布，
保存图标按当前状态保存；发布图标立即发布，Ctrl/⌘+S 按当前状态保存。
请求中会禁用相应操作，版本冲突或保存失败保留表单。

自定义页面的“Dock 图标”从本地 Material 图标集中选择，随页面的版本一起保存。

正文图片保存时会补全原始宽高属性，随正文和修订历史保留；媒体库复制的 Markdown
已经包含尺寸。保存优先复用媒体库原图元数据，封面直接引用已存储的媒体尺寸。
外部正文图片无法读取尺寸时仍允许保存，并用黄色 Toast 提醒；修复链接后重新保存，
或填写已知宽高即可补全比例。保存接口失败以红色 Toast 提示，表单输入保留。
旧正文重新保存后即可补齐原始比例，详细语法见 [媒体手册](media.md)。
只有已发布且启用导航的页面显示在公开 Dock 中，导航排序规则保持不变。
旧客户端省略图标字段时默认 article；无效名称由业务层与数据库拒绝。
已有部署先运行 `sloray migrate up`，应用仅增加 pages.dock_icon 的第八条迁移。

公开文章标题下显示摘要；正文下方保留审核后的评论列表。
文章阅读进度仅显示主题主色条，背景透明；独立页面不显示阅读进度。
点赞、评论、编辑入口按当前资源与登录权限出现在 Dock，Rust 接口继续校验权限与 CSRF。
评论图标打开输入/提交弹窗，并可选择当前列表中的评论作为回复对象。
关闭弹窗保留当前页草稿，切页时提示是否放弃；取消离开会重新打开原评论内容。
