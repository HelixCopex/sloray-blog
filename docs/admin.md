# 管理后台

单人博客直接访问 `/login` 登录。访客导航不显示写作或登录入口；登录成功后进入
文章管理，并显示“管理后台”入口。再次访问 `/login` 会回到后台。
后台导航集中提供文章、页面、媒体、评论、账号和设置；作者只能访问自己的文章和评论。

## 文章与 Markdown 写作

点击“新建文章”，填写标题、地址和正文。地址使用文字、数字、短横线或下划线，
公开地址为 `/posts/地址`。编辑器支持只编辑、只预览和分栏，输入后自动更新预览。
预览和公开正文使用相同的 Markdown 渲染与 HTML 清洗，支持列表、表格、代码和图片。

“保存后状态”决定按钮动作：保存草稿、发布文章或保存定时发布。
草稿只在后台可见；定时发布必须填写未来的北京时间，并需要运行 worker。
Ctrl/Cmd+S 保存；离开未保存的内容时浏览器会提示。发生版本冲突或地址重复时保留输入，
按提示更换地址或复制正文再重新加载。文章编辑后可查看修订历史。

点击“打开媒体选择器”，可以上传 PNG/JPEG/WebP 或取用媒体库中的图片。
图片处理完成后，点击图片会将 Markdown 图片链接复制到剪贴板，关闭选择器后粘贴到正文。
可以填写图片说明；剪贴板权限被拒绝时，下方显示可手动复制的链接。
封面通过媒体选择器的“设为封面”选择，也可以“移除封面”；保存文章后生效。
上传错误详情和重试见 [媒体文档](media.md)。

## 独立页面

管理员在“页面”中创建关于、联系、友链等内容，编辑和预览方式与文章相同。
页面地址位于根路径，例如 `about` 对应 `/about`；`login`、`admin`、`posts` 等系统路径不可使用。
保存草稿时不会公开；发布后立即生效，不需要构建前端。
勾选“显示在站点导航中”后，已发布页面会出现在导航里；排序数字越小越靠前。
不显示在导航的已发布页面仍可直接访问，并收录到 sitemap。撤回为草稿或删除后返回 404。
更改页面地址后旧地址返回 404，不会自动重定向。

新增 expand 迁移创建 `pages` 表，并将默认“关于”内容迁入数据库；不修改历史迁移。
更新现有部署时，按正常发布流程先执行 `sloray migrate up`。页面更新与 CDN purge 任务在
同一数据库语句内提交；运行 worker 消费 outbox。`404` 保留为应用错误页。

单人使用无需创建额外账号；需要协作时才在“账号”创建作者或管理员。
所有后台页面提供退出登录；运行时设置仍由 Rust 渲染，保存逻辑保持原有验证和原子配置更新。
