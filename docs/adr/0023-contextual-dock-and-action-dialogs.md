# ADR-0023：页面上下文 Dock、动作弹窗与持久切页

- 状态：已接受
- 日期：2026-10-10
- 取代 ADR-0021 的独立品牌首页入口和阅读工具；扩展 ADR-0022 的图标导航。

维护者要求所有主要文章操作由当前页面的 Dock 提供，包括后台保存/发布/删除。
确认使用内置 Material 页面图标、正文下方评论列表、弹窗输入与回复、轻量滑移/缩放切页，
并在离开未提交评论时提示是否放弃。Postgres 权威、鉴权/CSRF、评论审核和原生群岛边界保持不变。

1. Dock 内的首页链接使用当前 favicon；独立品牌图标移除。第八条 expand 迁移仅增加
   pages.dock_icon，旧页面默认 article，图标来自受控本地 Material 集合。
   编辑器、DTO 与数据库约束使用相同名称；版本锁与既有 purge 触发器继续生效。
2. Dock 由 SSR 页面上下文提供操作集：普通页面导航；文章点赞、评论和有权编辑入口；
   独立页面管理员编辑入口；后台编辑页保存、发布、媒体、预览和删除。
   业务权限继续由 Rust 检查，前端隐藏操作不能替代鉴权。
3. 搜索打开原生 dialog 和黑色遮罩，确认后以 Astro 导航到 /search?q=…；无 JS 链接仍可访问搜索页。
   评论输入/提交/回复选择放入 dialog，已审核评论仍 SSR；正文无点赞/回复/提交按钮。
   弹窗保留焦点约束、Escape、关闭后焦点返回；提交失败保留输入；切页前提示未提交内容。
   历史导航守卫在 ClientRouter 初始化前注册，再向当前弹窗派发可取消检查；取消时恢复历史条目，避免先启动的 AJAX 换页覆盖草稿。
4. Dock 使用 transition:persist，并在交换前按稳定操作键同步当前页链接、权限和目标，
   保留不变按钮的 DOM、外观与动画。支持 DOM moveBefore 的浏览器保留移动生命周期；
   旧实现按目标与动画名称恢复 CSS 时间线，避免重新开始。异步点赞结果仅更新对应文章，离开即失效。
   主区域使用方向性位移与缩放，不使用透明度淡入淡出，尊重减少动态效果偏好。
5. 摘要替代阅读时间/字号/专注阅读栏，移除这三项偏好和正文操作按钮，保留非交互阅读进度与随动目录。
   后台表单在 Dock 初始化前保留原有操作入口；正常交互时主要动作只显示在 Dock。

不引入 UI 框架、动画依赖或新的存储。迁移仅加列，旧二进制的显式 SQL 不受影响。
回滚时旧界面不会显示图标配置，但数据仍保留。发布需先应用第八条迁移。

参考：[Astro transitions](https://docs.astro.build/en/guides/view-transitions/)、
[Router lifecycle](https://docs.astro.build/en/reference/modules/astro-transitions/)。
