# ADR-0012：Web 安装向导 + 单一二进制 + 内置 systemd 单元

**状态**：已接受

## 背景

最初的部署流程要求：SSH 上服务器 → 编辑 `/etc/sloray/api.env` 填数据库连接串 →
重启服务。这个流程有一个很硬的缺陷：**配置写错就起不来**。

- 密码打错一个字 → 进程直接退出，你只能再 SSH 上去改文件；
- 这正是"部署流程不够友好"的根源：所有配置都发生在服务启动**之前**，
  而服务没有任何机会告诉你哪里错了。

同时，`cargo install` 只能安装可执行文件，无法把 systemd 单元放进
`/etc/systemd/system`，所以"用 cargo 装完就能开机自启"做不到。

## 决策

三件事一起做：

1. **引入 Web 安装向导**（`/setup`），采用"一次性 setup token"鉴权。
   服务在**未配置状态下照常启动**，用 token 打开向导填写数据库、S3、站点地址，
   配置写入 `/srv/sloray/shared/config.json` 并立即生效。
2. **合并为单一二进制** `sloray`，子命令：`serve` / `migrate` / `systemd` / `setup-token`。
3. **把 systemd 单元模板编进二进制**，用 `sloray systemd install` 渲染落盘并启用。

## 理由

1. **"起不来"是最差的失败模式。** 让服务在配置缺失/错误时仍能监听，
   把错误信息展示在页面上，比让人去 `journalctl` 里翻好得多。
   代价是进程多了一个"降级"状态 —— 这是值得的。
2. **向导必须自包含。** 它要能在"还没有数据库、可能还没有 Caddy、域名、TLS"
   的时刻工作，所以由 **Rust 自己渲染 HTML**，不依赖 Astro。
   零依赖是这个功能的**必要条件**，不是风格选择。
3. **一次性 token 而不是固定密码。** 未配置的实例一旦被公网扫到，
   `admin/admin` 级别的默认凭据就等于把实例送人。token 是 244 位随机值，
   写 0600 文件并打印到 journald，取用成本与固定密码相当，但不可猜。
4. **单一二进制。** systemd 单元、迁移、setup token 都与"二进制在哪"强相关；
   拆成多个二进制只会让路径与版本更容易对不上。`cargo install` 也只需装一次。
5. **模板编进二进制。** 用 `current_exe()` 取真实路径，而不是猜
   `~/.cargo/bin` 或 `/usr/local/bin`。同时 shell 侧（`activate-release.sh`）
   渲染同一份模板，保留"只有一份事实来源"。

## 代价与约束（必须守住）

* **这是引入 Web 配置界面后唯一的加固放宽点**：systemd 单元从
  "全盘只读" 变成 `ProtectSystem=strict` + `ReadWritePaths=/srv/sloray/shared`。
  **不要再扩大它**，单元测试里有一条断言守着"可写路径只出现一次"。
* **配置文件必须用 JSON**：它要写数据库密码和 S3 secret，
  `serde_json` 的转义经过海量验证；手写 TOML 字符串容易在引号/反斜杠上翻车。
* **`Recoverable` 状态是刻意保留的**：配了数据库但连不上时，
  `/setup` 依然接受 token。否则一个写错的密码又会让实例只能靠 SSH 恢复，
  等于把刚解决的问题重新引入。
* 页面里**绝不回显**连接串密码（`mask_database_url` 有测试覆盖）。
* 一切进入 HTML 的动态值都必须经过 `html::escape`（有测试覆盖属性注入）。

## 与既有决策的关系

* **修订 ADR-0006**：迁移仍然不在 `serve` 启动时跑；
  但 setup 向导**可以**在执行首次配置时跑一次，走同一把咨询锁
  （`migrate_up_with_lock`）。这是"一次性初始化"，不是常规启动路径。
* ADR-0007（数据库会话）不变：向导完成后，登录态仍走 `sessions` 表。
* ADR-0011（在 VPS 上编译）不变，且与"`cargo install` 装单元"是互补的：
  前者是版本目录部署，后者是更轻的安装方式。

## 重新评估的触发条件

* 如果将来支持多租户或多实例共享配置，文件级配置会成为瓶颈；
* 如果引入需要重启才能生效的配置项，向导需要增加"重启服务"的引导。
